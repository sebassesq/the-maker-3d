# The Maker, design v7: interactive 3D model

Interactive 3D model of "The Maker", the autonomous vehicle of team CSS (Queretaro, Mexico) for the WRO 2026 Future Engineers International Final.

**Open it: https://sebassesq.github.io/the-maker-3d/**

Rotate it, zoom in, take the vehicle apart and see the name of every part, in the browser, with nothing to install.

This repository only publishes the page. The documentation, the SolidWorks assembly and the source of this page are in the team repository: https://github.com/alex309-duarte/WRO_Future_Engineers_Queretaro_CSS (folder `models/cad/viewer`). License: MIT, as the team repository.
